# 实时任务过程显示

Streamlit 聊天界面在等待期间展示任务过程与方法摘要，包括当前操作、
已识别的工具名称，以及每秒更新的总耗时和当前步骤耗时。
执行结果返回后会记录状态；模型可在下一轮摘要中说明已核实的结果和下一步。
完成后，过程记录保留在回答的折叠区域中。

模型通过独立的公开输出字段提供摘要：

```xml
<progress>正在查询 CD19 的结构资料，接下来核对抗原链和残基编号。</progress>
<execute>...</execute>
```

只有完整且长度受限的 `progress` 块会显示；兼容逐 token 流和仅完整消息输出的模型。
原始内部推理、代码参数和执行日志不作为过程摘要展示。模型未提供摘要时，
界面仍显示实际阶段、可识别的注册工具名称和计时，不虚构进度百分比。

等待更新在后台线程消费服务流，所有 Streamlit 渲染仍在界面线程进行。
关闭消费流后，在当前模型或工具调用返回时停止后续步骤并清理迭代器；
这不是强制取消正在运行的计算。现有服务锁与会话隔离继续生效。

这项修改改善等待反馈，不改变模型推理或科学计算的实际耗时。
更新代码后需重启 Streamlit 进程，以重新创建采用新提示词的缓存 Agent。

验证：

```bash
pytest -q tests/test_live_progress.py tests/test_agent_session_isolation.py \
  tests/test_biochat_streamlit_smoke.py tests/test_ui_sessions_and_auth.py
```

上述测试使用模拟模型事件，覆盖摘要流式展示、工具调用、等待计时、
关闭清理、错误传播和会话隔离；真实模型是否稳定生成摘要还需部署环境验证。
