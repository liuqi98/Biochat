# 从 CD19 项目提炼的抗体设计方法

## Metadata
**Short Description**: CD19 项目经验、VH-only 单域化、ProteinMPNN、RFdiffusion、H3 重设计；路线选择、试跑门槛、表位保持和评分语义。仅方法，无项目序列或候选库。
**Version**: 1.0
**Last Updated**: 2026-09-09
**Source**: 用户提供的 CD19 项目方法记录；正文列出原始报告相对路径。

## Overview
把 CD19 项目经验用于新的抗体设计任务时，复用决策流程、检查项和证据要求。
项目中的残基位置、热点、H3 长度、筛选阈值、采样温度、构象和面板配额不能自动迁移。
本模块不提供 CD19 序列、候选排名或实验验证结果。

## Agent 使用方式
先调用 `get_antibody_design_method(route=..., antibody_format=...)` 获取输入要求和流程。
明确新项目输入、保护区域、阈值和资源预算后再选择执行工具。
已有检查结果时调用 `assess_antibody_design_evidence(evidence=..., stage=...)` 核对门槛和评分语义。
这两个工具分别返回方法计划和证据检查，不执行 ProteinMPNN、RFdiffusion、RFantibody、IgFold 或 Rosetta。
不能把“生成方法计划”报告为“已完成设计”，也不能把历史项目结果用于新任务。

## 路线选择
| 情况 | 路线参数 | 操作与验收重点 |
|---|---|---|
| 已有可用复合物，希望探索指定位置的序列 | `fixed_backbone` | 固定抗原和保护位点；ProteinMPNN；按输入构象与掩码分别保留来源 |
| 已有复合物，希望改变局部骨架 | `partial_diffusion` | RFdiffusion 局部扩散；先筛骨架，再对通过的骨架做 ProteinMPNN |
| 保持 H3 长度，仅优化该区域 | `h3_only` | 按母体分别设计，固定区域外序列与保护位点；同骨架配对比较 |
| 改变 H3 长度 | `h3_length_redesign` | 使用支持可变长度的结构设计流程；重新编号并检查 H3 边界、几何、表位和结构置信度 |

若只有短肽或序列，没有可用复合物，只能做相应的序列级探索或先补结构。
不要把短肽上的 CDRH3 代理评分当作完整抗原结构约束设计的替代。
人源抗体衍生的 VH-only、天然 VHH 和配对 VH/VL 要分别说明，不能互换名称。

## 四条优先级规则
1. 输入映射和小批量试跑通过后才扩量。缺结果或工具报错不算通过。
2. 先筛固定区、序列、几何与目标表位，再讨论分数。低能量不能覆盖硬筛失败。
3. 分数必须有来源、单位、参考和适用条件；配对差值与绝对界面能分开解释。
4. 计算通过后仍按对照、路线平衡、多样性和不确定性组面板，实验结论以实测为准。

## 可迁移的失败经验
CD19 的长度重设计探索表明，复合物预测或能量指标有利时，仍可能未通过预定表位或几何门槛。
此时应检查热点定义、链与编号映射、设计区域和构象，再修改设计或补证据。
不能为得到“通过”的面板而静默放宽门槛；若确需改变标准，记录版本、理由并重新评估全部相关候选。
