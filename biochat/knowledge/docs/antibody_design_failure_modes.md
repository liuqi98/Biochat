# 抗体设计中的失败识别与处理

## Metadata
**Short Description**: CD19 方法经验的通用失败规则：编号混用、越界突变、权重缺失、表位失败、RMSD 混用、绝对界面能与配对差值混用、TAP/TNP 适用性及缓存污染。
**Version**: 1.0
**Last Updated**: 2026-09-09
**Source**: 用户 CD19 项目记录的方法提炼，无具体候选或序列。

## Overview
使用这些规则诊断失败并决定下一步。保留原始失败，不用后续有利指标覆盖早期失败。
证据检查工具基于调用方提供的记录作判断，不能替代真实计算或文件完整性验证。

## 决策表
| 触发情况 | 解释与处理 |
|---|---|
| 链/编号/热点映射未验证 | 停止扩量；核对原编号、裁剪偏移、插入码和设计工具编号 |
| 保护位置改变或 H3 以外发生非预期变化 | 判固定区域失败；修复掩码并重新设计，不只修报告标签 |
| 设计 H3 长度与 IMGT 长度不同 | 先核对各自边界并显式记录，不能默认结构生成出错或擅自截断 |
| 模型权重缺失或为空 | 该工具记为未运行；替代工具必须明确来源与构象/指标差异，并重新验证 |
| 有利界面能但目标表位或几何失败 | 标为需要重设计；检查热点、边界和构象，不能升级为最终交付候选 |
| 能量字段名为 ddg，却没有配对参考 | 按实际协议核定是否只是单个复合物界面能；禁止声称相对母体改善 |
| 配对差值使用不同骨架或不匹配协议 | 不能按有效配对差值解释；补同条件参考计算 |
| 低全局 RMSD 掩盖局部 H3 改变 | 分开检查框架和 H3；指定对齐与测量区域 |
| TNP 参考颜色有利但表位失败 | 保留表位失败；开发性指标不判断目标结合是否正确 |
| 人源 VH-only 被当作 VH/VL 或天然 VHH | 修正格式和工具适用性；不自动补轻链，不将参考分布视为校准结果 |
| 单次评分很有利但重复方差高 | 报告不确定性并复核，避免只按极值排名 |
| 新序列沿用旧评分/结构缓存 | 按输入、序列、模型和协议哈希失效缓存，重算并更新证据 |
| 没有某项检查或实验结果 | 明确 `not_run` / 未提供，不以零值、默认通过或模型推断填充 |

## Agent 验收顺序
对 pilot，任一硬筛失败就停止扩量。对候选，任一硬筛失败就要求修复/重设计。
没有失败但缺少证据时返回证据不足。硬筛通过只允许继续计算优先级和面板选择。
实际实验亲和力或开发性结论始终需要相应实测证据，本模块不提供这些结论。
