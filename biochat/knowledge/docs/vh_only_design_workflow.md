# VH-only 结构设计与证据验收流程

## Metadata
**Short Description**: 通用 VH-only 抗体设计 SOP：结构与编号核验、pilot、固定骨架/局部扩散/H3 长度设计、硬筛、配对能量、开发性、多样性与溯源。
**Version**: 1.0
**Last Updated**: 2026-09-09
**Source**: 从用户 CD19 项目提炼；不含项目候选、序列、固定阈值或模型权重。

## Overview
Agent 负责明确任务约束、选择已有工具、记录事实和解释结果。
方法工具不代表相应计算后端已经安装。实际运行前检查软件、环境、可用权重、硬件和输入文件。
失败阶段要明确保留 `fail` 或 `not_run`，不能生成看似完整的结果代替缺失计算。

## 输入与编号
- 写明目标、抗体格式、母体来源、复合物构象来源和所需设计区域。
- 保存原始序列编号、PDB/mmCIF 链与残基编号、标准抗体编号之间的映射，处理插入码和裁剪偏移。
- 明确 H3 的定义与范围。设计工具的 H3 长度和 IMGT H3 长度可能使用不同边界，不能直接混用。
- 把可变位置、保护位置、抗原固定区域与热点写成项目配置，逐一核对，不能照搬 CD19 的位置编号。
- 结构转换后检查链长度、残基对应关系、缺失原子及预期保留的坐标；固定对象以任务配置为准。

## Pilot 与批量生成
先用少量样本验证环境、权重、输入映射、可变掩码、保护位置、序列输出、结构几何、目标保持、热点恢复及产物完整性。
记录随机种子、命令参数、版本、权重哈希和输入哈希。通过后按预算扩量。
中断产物与成功产物分开标记；恢复运行后复核完整性，避免把部分写出的文件计入正式结果。
局部扩散路线先筛骨架，再分配序列；按构象、设计强度、掩码和模型分别汇总通过率与失败原因。
停止阈值应在扩量前明确，由新项目配置提供，不从历史通过率倒推。

## 硬筛与结构检查
- 固定区域保持；序列仅改变允许位置；保护残基、长度和结构边界符合当前任务。
- 检查额外半胱氨酸、潜在糖基化基序、疏水簇、电荷及其他序列风险；区分专门设计的机制对照与待优选候选。
- 检查二硫键几何、主链连接、严重冲突、框架保持和目标表位接触。阈值及原子定义必须留档。
- 单独建模 VH 可检查游离态合理性；从复合物提取 VH 仍是结合态构象，不能称为重新预测的游离态。
- 对改变长度的 H3，重新检查边界连接与残基映射；一般结构置信度通过不自动代表表位或几何通过。
- 每项证据使用 `{status: pass|fail|not_run, evidence_ref: 产物标识}`；外部文件是否存在、哈希是否一致仍由执行层核验。

## 分数与比较
每个分数记录方法、值、单位、来源、参考、计算协议、重复和不确定性。
ProteinMPNN 等序列兼容性分数不能标成亲和力。
Rosetta 的界面能使用明确的输出字段和 REU；字段名含 `ddg` 也不一定是突变相对母体的差值。
配对差值定义为候选减参考，要求同骨架、匹配协议，并报告有利重复比例与方差。
负值只能支持该计算条件下方向有利，不能换算为 Kd、亲和力倍数或声称实验提升。
不同骨架和不同 pose 的绝对界面能不能直接横向推断亲和力；高方差结果保留为不确定性。
RMSD 必须说明参考结构、对齐区域、测量区域和原子集合；抗原骨架、全 VH、框架、CDR RMSD 分开保存。

## 开发性与面板
按输入格式检查工具适用性。VH-only 不为使用 TAP 而随意补配轻链。
使用 TNP 时记录结构来源、构象状态和参考人群/分布；人源 VH-only 对纳米抗体参考分布的比较应标为探索性。
参考颜色不能证明开发性通过，也不能覆盖已有表位或几何失败。
选择面板时保留母体和机制对照，兼顾不同路线、构象、模型来源及序列多样性。
最后输出计算证据、未测项目及后续表达、单体比例、稳定性、同价态结合、竞争/表位和细胞验证计划。

## 产物最小记录
使用唯一的项目/轮次/候选标识，保存母体和路线谱系。序列、结构与评分以哈希关联。
每次运行记录软件版本、模型权重、种子、参数、输入输出、成功/失败状态及恢复记录。
改了输入或序列必须使旧评分缓存失效；报告只能引用当前候选和当前版本的真实产物。
